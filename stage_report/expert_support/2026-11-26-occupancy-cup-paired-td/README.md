# place_empty_cup 配对占据奖励与 Native TD

冻结 C_paired。20 对查询首帧的 RGB、状态和 logit 逐对一致。H10 SFT 查询级转移共 523 条，其中训练 395 条、验证 128 条。下一状态原始奖励均值 4.568，达到上限 5 的比例 62.3%。折扣 0.9，Q 和 V 各训练 10k 步。

- Q 的最优步数 10000，训练 / 验证 MC RMSE 为 0.315 / 15.998。
- V 的最优步数 10000，训练 / 验证 MC RMSE 为 0.272 / 12.993。

四条验证轨迹各取三个观察。K32 平均极差 0.1345，两两平均绝对分差 0.0366，β=1 的 ESS/K 为 0.99815。

20 个闭环场景与训练及选模场景隔离，沿用 V1 的评测种子。Native 复用 V1 实际轨迹并重新打分。其余三组使用新 Q 全程运行，每次查询采样 32 个候选。固定窗口取每个回合前五个真实查询到达状态，每场景等权。

按场景配对 bootstrap，以下为前五次平均奖励差及 95% 区间。

- max-min 为 +0.070，区间 [-0.259, +0.408]。
- max-random 为 -0.078，区间 [-0.474, +0.340]。
- min-random 为 -0.149，区间 [-0.487, +0.197]。

四个开发场景同时用于 checkpoint 选择。每种方法每个评测场景各运行一次。逐回合几何量、原始奖励、截断奖励及成功标记见 [online.json](online.json)，配对统计见 [fixed_window.json](fixed_window.json)。

Max-Q 比 Random 少成功 2 个场景，比 Min-Q 少成功 3 个场景。前五次平均奖励的 Max-Q 与 Min-Q 差值区间包含零，且 Random 均值最高。当前结果尚不足以确认占据引导有效。Q 的训练误差较低、留出误差较高，候选分差也较小，后续需要继续检查动作价值的泛化与区分能力。
