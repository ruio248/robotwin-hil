# 专家支撑函数阶段结果（2026-11-24）

本目录接续 [原 BCE 基线](../2026-11-23-matched-sft/README.md)，归档同观察候选距离排序、延长训练与 K32 候选扩充实验。

## 方法与数据

模型接收三视角冻结视觉特征、14 维机器人状态和完整动作 chunk。click 使用 H50，shoes 与 cup 使用 H10。训练为专家/策略 BCE 加候选对 softplus 排序损失，排序系数为 1。候选距离由训练侧动作尺度归一化后的关节误差与夹爪误差各占一半构成。只比较距离差超过训练分布第 25 百分位的候选对，先在观察内平均，再对 batch 平均。

train50/test20 按 episode 划分。AdamW 学习率 1e-4、weight decay 1e-4、batch 256、梯度裁剪 1。长训练按原随机序列重放，10k 权重逐张量核验一致后继续；shoes 30k 的记录点也与后续100k运行一致。

|place_dual_shoes|30,000|80.82%|52.36%|0.543|未测|

在线每次采样32个完整chunk，直接执行最低原始logit候选。β=1 ESS/K 是另行计算的软权重诊断。成功分AUC以一条轨迹内查询分数的均值区分成功与失败。候选排序准确率衡量同观察下专家距离顺序。

## K32 数据扩充

两项train50/test20均保留原4个候选并新增28个，70条逐文件核验状态、特征、专家chunk和K4前缀一致。新增候选使用相同SFT checkpoint、RGB、状态和指令。

K32训练运行10,000步。旧模型与新模型共用K32候选及训练侧阈值评测，详见 [K32统一对照](k32_ablation.md)。K32新模型在线成功率尚未测量。

## 结果解读与产物

click距离排序明显改善。shoes与cup延长训练主要提升训练集拟合，test20变化较小。K32扩充的第一轮10k训练未显示独立场景排序提升。原50条SFT轨迹的结局AUC与同状态动作排序测量不同能力。

- data_manifests 包含K32清单。
- scripts 包含本地实验脚本快照，绝对路径对应训练机环境。
