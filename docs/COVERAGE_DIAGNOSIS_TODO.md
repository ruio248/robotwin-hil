## 1 为什么分数集中在 40

需要区分分数的整体基准值与同一观测下的动作区分度。整体基准约为 40 不会直接削弱 softmax；所有候选减去同一个 40，权重完全不变。决定权重的是分数差与 beta 的乘积。

### 已核验训练曲线

读取 `new_power_3` 上正式 alpha 1.0 训练的完整验证记录：

| 训练步数 | 验证专家动作分数均值 | 跨验证转移标准差 |
| --- | ---: | ---: |
| 1000 | 6.46294 | 0.19744 |
| 2000 | 10.94577 | 0.19217 |
| 5000 | 23.32859 | 0.13851 |
| 8000 | 34.08632 | 0.08763 |
| 9000 | 37.34190 | 0.08327 |
| 9500 | 38.91523 | 0.07120 |
| 10000 | 40.45765 | 0.06641 |

因此 40 是训练到 10000 步时的数值水平，尚不能称为收敛值。均值仍在上升，而且四个 alpha 的终点均值都在约 40.33 至 40.46。

当前 TD 信号为常数 1，gamma 为 0.99。若网络近似常数、保守项差异接近零，忽略其他优化影响，其自洽固定点满足

\[
m=1+0.99m\quad\Longrightarrow\quad m=100.
\]

这只是近似常数分支的分析，不代表完整目标一定收敛到 100，也不代表分数具有概率含义。

### EMA 可以解释训练到 40 的时间尺度

设在线网络迅速拟合 target，且参数 EMA 可近似为输出均值的 EMA，则

\[
m_n\approx1+\gamma\bar m_n,
\qquad
\bar m_{n+1}\approx(1-\eta)\bar m_n+\eta m_n
=[1-\eta(1-\gamma)]\bar m_n+\eta.
\]

代入 gamma 0.99、EMA 系数 eta 0.005，并用初始 target 均值约为 0 的简化条件，得到

\[
m_n\approx100-99(1-0.005\times0.01)^n,
\qquad m_{10000}\approx39.95.
\]

该近似与观测到的 40.46 很接近，支持“常数 TD 信号经慢速 target 网络传播，形成仍在上升的整体基准”的解释。非线性网络的参数 EMA 不严格等于输出 EMA，39.95 是解释时间尺度的近似预测。

另外，在 45 条 val 轨迹中，每条均匀选择 4 个有效转移，共 180 个固定观测进行直接前向检查：

| 检查项 | alpha 1.0 结果 |
| --- | ---: |
| 相同后继观测和候选上，online 分数减 target 分数的均值 | 0.60001 |
| 使用 EMA target 的 TD MSE | 0.0001169 |
| 后继评分改用当前 online 网络的自洽残差均值 | -0.59679 |
| 上述自洽残差的 MSE | 0.35623 |

自洽残差定义为 `B_online(o,aE) - [1 + gamma * mean B_online(o_next,a_pi_next)]`，仅用于诊断，未改变训练目标。结果说明“小的 EMA TD loss”表示网络跟上了缓慢移动的 target，不等于已经达到固定点。

## 2 接管率为何没有明显改善

目前历史 HG-DAgger 与人工按 e 的增强采集并非严格配对实验，因此“没有明显改善”应作为待解释的观察，尚不能据此确认真实效果为零。算法层面已有直接证据：当前增强动作几乎等于同候选的均匀平均。

### 已核验候选到执行动作的关系

对已有 430 次 active enhanced 决策重新统计，N 为 4，beta 为 10，全部采用首动作评分和完整 chunk 加权平均：

| 环节 | 观测结果，中位数 |
| --- | ---: |
| 原始首动作候选两两关节 RMS 距离 | 0.001509 rad |
| 四个候选覆盖分数范围 | 0.0004444 |
| 最大候选权重 | 0.25053 |
| ESS | 3.999987，满值为 4 |
| enhanced 与 vanilla 均值首动作 RMS 差异 | 0.00000124 rad |
| enhanced 与 vanilla 完整 chunk RMS 差异 | 0.00000512 rad |

距离使用 12 个机械臂关节，排除夹爪；完整 chunk 指其 10 个动作的整体 RMS。上述距离比较是计算出的物理关节目标，不是环境运行后的状态差异。

可直接确认的是：候选之间存在较小差异，已有候选上的分数差相对于 beta 10 很小，因此 softmax 几乎均匀，加权均值相对于均匀均值几乎不动。该现象为增强偏置贡献较弱提供机制证据。接触任务可能对小动作敏感，动作差异小本身不能代替闭环结果验证。

### B 是否完全不看动作

在上述 180 个 val 观测上，固定图像特征和状态，只对专家动作的 12 个机械臂关节添加离线随机方向扰动。每个观测使用相同的 16 个方向，控制每个方向的关节 RMS 幅度，夹爪保持不变。

| 扰动的关节 RMS 幅度 | alpha 1.0 的绝对分数变化中位数 |
| --- | ---: |
| 0.002 rad | 0.001289 |
| 0.010 rad | 0.006380 |
| 0.050 rad | 0.026693 |
| 0.100 rad | 0.050694 |

这里的分数变化为 `abs(B(o,aE+delta)-B(o,aE))`。这组输入仅用于网络敏感性测试，没有执行，也没有验证动作可行性。结果排除了“网络对所有动作完全恒定”的说法；它不能证明网络正确识别了风险或长尾程度。

这些测试基于示范 val 观测，前一张表基于在线 HIL 采集观测，且候选数量、动作方向和统计量不同，不能直接把两张表的分数幅度当作配对因果比较。下一步应在同一组真实线上观测上，用同幅度、同候选数的对照，检查策略候选是否主要沿 B 不敏感的方向变化。

### 只改变 beta 会怎样

使用相同 430 组候选与原始评分做离线重加权，未修改线上配置：

| beta | 最大权重中位数 | ESS 中位数 | 首动作相对均匀均值 RMS 差异中位数 |
| --- | ---: | ---: | ---: |
| 10 | 0.25053 | 3.99999 | 0.00000124 rad |
| 100 | 0.25532 | 3.99874 | 0.00001231 rad |
| 1000 | 0.30466 | 3.88503 | 0.00011923 rad |
| 10000 | 0.65905 | 1.92816 | 0.00065585 rad |

即使直接选择最低 B 候选，首动作相对于均匀均值的 RMS 位移中位数也约为 0.0009885 rad。四候选相对于均值的最大半径中位数为 0.001434 rad。任何非负归一化加权平均都留在候选凸包内，其位移受候选范围约束。

因此增大 beta 能改变权重，但不能凭空扩大已有候选支持范围。这张表只衡量离线动作变化，不代表大 beta 会提高接管率或数据质量。

闭环实验的主要接管指标应是人工按键请求概率。请求、接受恢复、成功恢复、保存有效 HIL 分别计数，并计入有效数据的采集时间。手动 e 触发带来的样本选择和历史 baseline 协议差异必须处理，不能通过挑选高接管轮次比较来得出效果结论。
