# 完整 action chunk 的 Coverage 两层研究协议

状态：实施中；正式结论只能来自已完成并通过完整性核验的结果。配置为 `RoboTwin/configs/coverage_benchmark_v1.json`。本轮不自动提交 GitHub，不开展人工接管率实验或 DAgger 微调，不改变生产 18300 HIL 服务。

## 一、问题与主张边界

第一层检验：在同一观测的完整动作 chunk 已有差异时，评分器能否区分候选，能否改变重采样权重及实际输出的加权平均动作。

第二层检验：这些排序和加权平均动作，在同一仿真状态实际执行时，是否对应更大的“基础策略难完成、规定脚本专家能恢复”的程度。允许差异不足、没有优胜方法或统计不确定。沿轨迹评分曲线仅是诊断，不是排序有效性的证明。

所有评分均为“越高越受专家支持”，低覆盖增强采样使用

\[
w_k=\frac{\exp[-\beta(B_k-\min_jB_j)/\sigma_{cal}]}{\sum_j\exp[-\beta(B_j-\min_jB_j)/\sigma_{cal}]},\quad
A_{MC}=\sum_kw_kA_k.
\]

分数平移不改变权重；评分尺度和温度只在校准集拟合一次，测试时不再改变。

## 二、共享输入、数据与方法

输入统一为三视角冻结 ImageNet ResNet18 特征（1536）、14维机器人状态、完整10×14绝对关节目标；顺序为左6关节、左夹爪、右6关节、右夹爪。不得把10步中的某步伪装成当前动作。

| 数据 | 数量 | 用途与限制 |
|---|---:|---|
| SFT train | 405 episodes / 11,461有效anchor | 四种方法同一训练样本；所有标准化仅来自此处 |
| SFT内部验证 | 45 episodes / 1,274有效anchor | 按文件排序后default_rng(42)打乱，前15轨迹校准、后30诊断；旧TD已监控这些数据，不能称独立测试 |
| 已保存HIL接管前 | 50轨迹 / 1,233观测 / K32 | 完整候选复用原缓存的随机嵌套顺序，不重新抽样 |
| 已保存HIL全轨迹 | 50轨迹 / 3,988观测 / K4 | 接管对齐曲线；建议动作不是人工实际执行动作 |
| 历史策略rollout | 100条，31成功/69失败 | 回顾性曲线，同时比较公共前缀；不是新的成功率评测 |
| 新仿真 | seeds 200000–200029 | 先核查已有episode/eval记录中的seed冲突；不做专家预检筛选 |

四种评分：

1. **Chunk TD-B**：复用seed42的1k/10k/20k，主结果10k。新增seed43/44，同缓存、同宏转移目标；三层256 LayerNorm+SiLU，gamma=.99，alpha=1，EMA=.005，AdamW lr/wd=1e-4，batch256，梯度裁剪1。目标保持原有 `sum(gamma**i,i=0..9)+gamma**10*mean B_target(next observation,next policy chunks)`；不新增terminal或正则。
2. **32近邻＋动作高斯核**：三视角各做L2单位化，state以训练均值/标准差标准化后除sqrt(14)。四观测块拼接除2。动作标准化后展平除sqrt(140)。只检索观测的32近邻，再对对应专家chunk的高斯相似度取平均；带宽是训练集中跨episode近邻专家动作距离的中位数。
3. **One-Class SVM**：相同特征，观测和动作各作为一个平衡块，拼接除sqrt(2)，RBF，nu=.05。gamma=1/(2*训练随机非自配对平方距离的中位数)，固定seed42的100,000对估计核尺度；全部11,461 anchor参与拟合。导出数值支持向量与系数，避免跨机器pickle版本问题。
4. **专家–策略来源判别器**：结构同TD，10k步，seed42/43/44；batch256个观测，每个观测一个专家正样本及4个策略候选，正负总权重各一半，BCE-logit目标，AdamW lr/wd=1e-4，裁剪1。它不是成功/失败分类器。

状态和动作std下限.05。仅观测近邻核支持度为负控制：同观测所有候选同分。另将候选池内分数随机置换；置换不产生额外实际平均动作分支。

## 三、第一层指标与校准

每个观测先计算候选max B − min B及std，再跨观测/轨迹汇总，绝不把一个时间段的不同状态混合后取极差。归一化分差除以一个全局sigma_cal；专家和策略两类在计算整体均值方差时各占1/2。

温度在15条校准轨迹的K4池上拟合，使中位ESS/K接近.5，之后包括K8/16/32均固定使用这个beta。预先限定beta≤100（作用于全局标准化分数）；若目标不可达到，报告实际ESS与无法达到原因，不继续放大。零整体方差或所有池内同分时标记退化、使用均匀权重。

完整chunk主动作指标：12关节Frobenius距离，及其除sqrt(10×12)后的RMS，单位rad；夹爪另报。首/末动作作为辅助。K4/8/16/32为同一个32候选池内的随机嵌套子集，不能把max随K的自然增长称为原分布变宽。

交付内容：

- 完整chunk平均及最大差异、原始/归一化评分分差随progress曲线；每5%分箱，先轨迹内均值，再轨迹间均值，同时保留中位数/IQR和每箱轨迹数。
- 同观测两两动作距离与绝对分差的Spearman分布（退化相关系数记null）。不假定距离越大必须低覆盖。
- 重复输入一致性、候选排列等变性；三个训练seed的排序相关性、最低分候选一致率及平分标记。
- ESS/K、最大权重、MC均值对均匀均值的完整chunk关节RMS偏移；评分置换对照。
- 100历史rollout成功/失败均值与IQR，归一化进度和全体公共前缀两种横轴。
- 50条HIL首次接管对齐均值/IQR与仅观测对照；0=首个人控保存帧，不等同于按键精确时间，不是物理秒数。

## 四、第二层实际分支

baseline9999、v2_promptfix、左臂交给右臂、固定修正提示词，绝对joint、完整执行10动作、take_action(qpos)、frequency字段30、900策略动作上限、原成功判定、headless。相机与预处理保持现有链路。SFT元数据15、线上字段30及save_freq15均单独记录；take_action含可变物理子步，不能把chunk机械地换算成固定时长。

每seed先跑完整基础策略，按seed循环分配20/50/80%决策进度，选择距离最近的决策前状态，每层10个。进度不是语义阶段。选择不看B、成功或接管。保存基础策略chunk及状态签名；重建场景回放前缀须通过1e-4一致性检查。

每状态固定8候选，微批次4×2。实际13方案=8候选+4主评分器MC平均+1均匀平均。每方案执行chunk至10动作/任务成功，保存末端快照。独立从末端分别续跑基础策略3次、脚本专家1次。专家自动选择阶段、不人工选择、不重试；先前策略长时间失败不影响这一次恢复测量。chunk内已成功的方案记终止成功，无需续跑。

显式推理噪声经专用18304服务传入policy.infer(noise=...)；记录完整噪声数组，不依赖客户端seed隐式控制服务。每状态每次重复的续跑噪声，在所有方案间相同。重置策略观测窗口。保留三次重复，最多1170次策略续跑和390次专家恢复。

### 必须通过的门槛

先3状态×2候选，在交错执行顺序后重复；物理状态、关节驱动目标、任务metadata、路径、计数器、机器人状态及Python/NumPy/Torch随机状态恢复。固定噪声输出可复现；专家恢复后重放不能污染原分支。最大误差≤1e-4、终止结果一致。未通过不启动正式实验；基础设施异常另记，不当作策略失败。

### 统计判定

记p_auto为3次自主完成率，r_expert为一次脚本恢复成败，U=(1−p_auto)r_expert。本协议下的可恢复困难程度不等同人工接管概率。另报告掉落、规划失败、时长、物理子步和位姿误差。

候选比较：最低/最高分候选与8候选均匀随机的期望结果比较。并列极值取并列集合期望，不任意取第一个。均匀随机也是分数随机置换后选择的精确期望。辅助检查点/训练seed只复用候选执行结果，不增加平均动作分支。

平均动作比较：四种MC方案各自实际执行结果减去均匀平均方案；不从原候选结果推断。30场景是配对独立单位，场景级bootstrap10000次给95%区间，分层另报。区间过宽/包含0则写不确定；恢复失败不能隐藏。只有排序和真实平均动作两部分均支持，才考虑“更适合当前增强采样”。

## 五、实施与恢复

入口：`RoboTwin/scripts/run_coverage_benchmark.py fit|offline|branch|report --config ... --profile new_power_3|ubuntu --output-dir ... [--resume]`。`branch --gate-only`仅跑3状态复现门槛。评分器接口 `score(features,state,chunks[K,10,14])->scores[K]`。执行期间用内核文件锁防重复进程，数值缓存/JSON原子写入；按完整方案断点恢复，不重用部分失败续跑作为完整方案。

`fit/`含模型、数值SVM、标准化、划分、校准、训练日志及sha；`offline/`含逐候选分数和逐观测指标；`branch/scene_seed/`含基准轨迹、状态签名、候选、权重、噪声、末端快照及13方案结果；`report/`含PNG/PDF和机器可读汇总。前3个预先指定场景保留代表视频，10fps只是编码速度，不宣称物理时间。

完成条件：四方法/控制/三个TD阶段的离线诊断完整；门槛通过后30场景全部记录，文件sha可核验；图表经过目视检查；结论明确区分离线分辨、候选排序、真实平均动作三类证据。若复现门槛未通过，明确报告失败证据与未执行项，不称研究已完成。
