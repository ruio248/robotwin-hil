# DART 接入说明（2026-10-16）

## 当前已实现的核心

`RoboTwin/scripts/dart_covariance.py` 实现了 DART 的联合高斯专家噪声核心：对**同一观测**下的学习策略动作与专家原本意图动作计算残差，估计 12 维双臂关节协方差，按 episode 等权或按 step 加权，支持整体 trace 标定、收缩和 PSD 处理。`noisy_expert_action` 仅扰动双臂 12 个关节，两个夹爪不动，调用者负责保留干净专家动作作为训练标签。

输入 NPZ 必须包含 `[N,12]` 或 `[N,14]` 的 `learner_actions`、`expert_intended_actions`；可选 `episode_offsets` 是从 0 到 N 的严格递增边界。两组动作必须对应**相同观测、相同关节顺序、相同频率和相同目标动作定义**；不能把异步缓存、执行后 qpos 或首动作/全 chunk 混用。当前只拟合单步执行目标协方差，不能把它当作 10 帧 chunk 的联合协方差。

示例：

```bash
python RoboTwin/scripts/dart_covariance.py \
  --pairs /path/to/aligned_expert_learner_actions.npz \
  --output /path/to/dart_covariance.npz \
  --shrinkage 0.1 --alpha-per-step 0.01
```

输出 trace 单位为 rad²。若给 `--alpha-per-step`，它表示每个专家控制步的 `tr(Σ)`，不是标准差，也不是整条轨迹 α；长为 T 的轨迹对应论文中的 α = T · tr(Σ)。默认不缩放，遵循论文中“与学习策略误差匹配”的主要做法。收缩仅是有限样本数值稳健选项，不是 DART 原论文定义的一部分。

## 尚未接入真实示范采集的原因

当前 RoboTwin 脚本专家用 `take_dense_action` 执行规划轨迹。原数据转换把**下一帧实际关节位置**存为训练 action；如果直接给规划轨迹加噪，转换后标签也会变成带噪执行结果。这不满足 DART 所需的“噪声执行、干净专家意图作标签”。此外，脚本专家在单段规划内没有逐步观测-纠偏接口；不能把一次开环脚本轨迹加噪声冒充可恢复的 DART 示范。

接入真实 DART 采集需要先新增独立专家接口：每个控制步从受扰状态取得干净目标，执行 `a_E+ε`，同时保存执行前观测、干净 `a_E`、执行 `a_E+ε` 及 episode 边界；数据转换明确用 `a_E` 作 action。随后用当前 learner 在相同观测下评分得到配对残差，更新 Σ，收集下一轮示范并重训。这必须使用新输出目录，不能改写已有 SFT/HIL 数据。

## JG 验证范围

JG 可用于独立的协方差/采样数值测试和配对数据上的离线尺度扫描。用户于 2026-10-16 授权后，已核实并结束旧测评 PID 3926226，仅释放显存，未删除历史输出。

从 new_power_3 的完整 chunk SFT 缓存中，按清单 SHA 验证后抽取 405 条训练 episode 的 11,461 个有效 anchor，使用同一观测下专家 chunk 与首个策略候选 chunk 的首动作。**专家动作为下一帧 qpos 代理，而不是脚本专家干净意图**；源数据 15 Hz，不得直接与线上 30 Hz 相等同。`dart_prepare_proxy_pairs.py` 显式写入该限制；`dart_proxy_scale_scan.py` 在 JG 按 episode 分成 324/81 的拟合/留出集做纯离线扫描。报告见 `outputs/dart_proxy_covariance_20261016/proxy_scale_scan.json`。

初始残差协方差 trace 为 `2.5283e-5 rad²`。乘以 0.25/0.5/1/2 时，每关节 RMS 分别约为 0.000726/0.001026/0.001452/0.002053 rad；在留出集模拟噪声的 RMS 95 分位约为 0.00108/0.00150/0.00218/0.00296 rad。它们只是代理噪声强度，不是成功率、有效 HIL 率，也不能据此选择最优超参。

真正的 DART 比较应固定 seed、专家脚本、采集数量、基础策略与 IWR 训练配置；必须先建立受扰状态下的干净专家纠偏动作标签，做 3 seed 冒烟与标签审计，再做配对场景成功率/接管率测试。不得以现有策略输出加噪 sweep 代替 DART。

## JG 仿真成功率扫描（2026-10-16）

用户明确要求成功率扫描后，新增独立的 `RoboTwin/scripts/eval_dart_noisy_expert_jg.py`，在 JG 的 `handover_to_tray_v2_promptfix` 上给**脚本专家的关节位置目标**注入同一步的 12 维相关高斯噪声，夹爪保持原样。基础协方差使用前述 405 条 SFT 代理动作对拟合，trace 为 `2.4156953e-5 rad²`。不筛选 seed，固定 120000–120019，每档各 20 条，零噪声也执行一次。专家在阶段边界重规划，非每步反馈；不保存干净专家标签，也不重训学习策略。因此这是“受扰脚本专家成功率”的 DART 风格安全扫描，**不是完整 DART 闭环策略成功率**。

首先要注意**回放不稳定**：同一 seed、同一倍率复跑时，零噪声从 19/20 变为 20/20（seed 120006 翻转）；256 倍从 15/20 变为 19/20，有 6 个 seed 的结果翻转。三个敏感 seed 的单独复核也出现结果翻转。基础任务设置会固定 NumPy、Python 和 PyTorch 种子；具体非确定来源尚未定位，可能与 GPU 规划/仿真有关，但不能直接归因。不能把首轮的 256 倍下降或 0.25/0.5 倍的 20/20 解释为可靠的噪声因果效应，更不能从这些档位中宣称最优 DART 超参。

所有扫描都有 20 个唯一 seed，无基础设施异常和非有限目标；`planned_joints_legal` 只检验规划器原始输出，**不能**证明每一个加噪后目标均在关节限制内。完整原始记录、汇总和复跑在 `outputs/dart_noisy_expert_jg_120000_120019_20261016/`。后续如果要做可发表的成功率比较，应先审计同 seed 回放差异，至少增加重复次数并对加噪目标做关节界限审计；要评估完整 DART，还必须接入干净专家动作标签、受扰后纠偏和策略重训。
