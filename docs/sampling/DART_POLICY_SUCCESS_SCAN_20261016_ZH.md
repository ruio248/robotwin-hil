# DART 噪声超参—学习策略成功率扫描

## 目的与解释边界

本扫描比较由不同 DART 风格专家扰动数据微调得到的**学习策略自主成功率**，不把受扰脚本专家的任务成功率当作学习效果。

当前 RoboTwin 脚本规划器在语义阶段边界重新规划，而不是每个仿真控制步都查询专家。因此本实验是 **DART 风格的阶段规划器适配**，不是论文中完全逐状态反馈的原样复现。噪声协方差来自已有 SFT 同观测动作残差代理；其动作标签有代理性，且 SFT 数据采样为 15 Hz。结果须按此边界解释。

## 固定对照协议

| 项目 | 固定设置 |
|---|---|
| 任务 | `handover_to_tray_v2_promptfix` |
| 扫描倍率 | `0, 0.5, 1, 2`，倍率乘在同一 12 维手臂关节协方差矩阵上；夹爪不加噪 |
| 采集 | 每档同一 seed 序列，各尝试 30 条专家脚本 rollout；逐条记录脚本成功、异常、关节合法性和数据路径 |
| 标签 | 保存未扰动的绝对关节规划目标；扰动后的状态进入后续观测 |
| 训练数据 | 原始 SFT + 当前倍率的 DART 专家数据，batch 内 32/32 |
| 模型与初始化 | Pi0.5、`state=False`、action horizon 10；从原 SFT-9999 初始化，全参数微调 |
| 训练 | seed 42，batch 64，FSDP 2 卡，不用 LoRA，不用 EMA；各组训练步数保持相同 |
| 策略评估 | 固定 50 个共同 seed `31000–31049`；同一提示词、任务配置、30 Hz、绝对 joint chunk、无人工接管、无专家预筛选 |

## 主要结论指标

主指标为完整任务自主成功率 `successes / 50`。同时报告逐 seed 配对胜/负/平、Wilson 95% 二项区间和相对 SFT-9999 基线的配对差。只按全部 50 个预定 seed 作分母；基础设施异常单列，不得偷偷换 seed 或删失败样本。若不同倍率造成专家采集失败，报告失败数，并确保训练集有效示范量可比；不得把失败示范误当成功纠正标签。
