# 专家支撑函数 D：评价指标

指标分四层，不能以某一层的高分替代另一层的结论。所有置信区间以 episode 为抽样单位，而不是把同一 episode 的连续锚点当独立样本。

| 层次 | 指标与方向 | 它**不能**证明什么 |
| --- | --- | --- |
| 同观测源排序 | `expert_rank = P(B_E>B_π)+0.5P(相等)`，在 episode OOF/独立 test 上算；越高表示专家与策略候选更可分。 | 不等于预测终局、预警失败或专家能救回。 |
| 候选分辨率 | `D_B` 为 K 条策略候选两两绝对分差的均值，除以独立校准集 score scale；同时报告分数范围、标准差与重复候选率。 | 大分差可能只是饱和；若候选动作相同，不能产生有效探索。 |
| 采样作用 | 权重 `w_k∝exp[-β(B_k-min B)/scale]`；报告 `ESS/K = 1/(K Σw_k²)`、最大权重、加权 chunk 与均匀平均 chunk 的关节 RMS/夹爪位移。 | 改变了动作或降低 ESS 不等于任务提升；权重故意偏向低支撑候选。 |
| 独立策略轨迹 | 对真实策略查询的 D 分数先做各折校准再平均；每 episode 算固定前 1/2/3/5/10/15 次查询及全轨均值，以实际终局成功为正类算 AUC、episode bootstrap CI。 | 全轨 AUC 受轨迹长度、阶段和未来信息影响，不能单独声称“提前预警”。 |

若有真实 HIL 事件，还需以**相同阶段、同风险窗口**的接管请求为正例、未接管的策略状态为负例，报告事件检出率、误报/小时或每 episode、提前量与覆盖率；X 放弃和恢复失败另列。没有真实人工接管标注时不能造标签，也不能把成功/失败 AUC 冒充 HIL 事件 AUC。

所有分数方向先验固定为“高 = 更像专家来源”。若成功/失败 AUC 小于 0.5，表示按此方向失败轨迹可能得分更高，不能仅凭反转符号报告理想分离度。全轨和固定前缀均需同时给出两类 episode 数、可用前缀数、查询次数/轨迹长度对照和任务阶段分布。独立 test 的同观测源排序与轨迹终局 AUC 是互补检验；结论以适用范围表述。
