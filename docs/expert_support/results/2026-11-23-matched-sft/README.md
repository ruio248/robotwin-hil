## 逐任务诊断

### click_alarmclock

- test20：专家/策略平均 logit 14.863 / -14.749；K4 同观察候选两两平均分差 0.0371；β=1 ESS/K 1.0000；加权关节 RMS 偏移 0.004 mrad。
- 50 条 SFT rollout：成功 34、失败 16；成功分 AUC 0.138（bootstrap 95% 区间 [0.035, 0.257]）。
- 在线 K32：77 次决策，候选平均分数范围 0.1676，β=1 ESS/K 1.0000；最低分候选相对候选均值的关节 RMS 偏移 5.946 mrad。配对成功率变化的 bootstrap 95% 区间 [+0%, +15%]。

### place_dual_shoes

- test20：专家/策略平均 logit 0.510 / 0.281；K4 同观察候选两两平均分差 0.1471；β=1 ESS/K 0.9846；加权关节 RMS 偏移 0.311 mrad。
- 50 条 SFT rollout：成功 24、失败 26；成功分 AUC 0.758（bootstrap 95% 区间 [0.614, 0.883]）。
- 在线 K32：896 次决策，候选平均分数范围 0.0678，β=1 ESS/K 0.9995；最低分候选相对候选均值的关节 RMS 偏移 3.251 mrad。配对成功率变化的 bootstrap 95% 区间 [-10%, +40%]。

### place_empty_cup

- test20：专家/策略平均 logit 1.202 / 0.451；K4 同观察候选两两平均分差 0.1475；β=1 ESS/K 0.9964；加权关节 RMS 偏移 0.053 mrad。
- 50 条 SFT rollout：成功 36、失败 14；成功分 AUC 0.996（bootstrap 95% 区间 [0.982, 1.000]）。
- 在线 K32：523 次决策，候选平均分数范围 0.2029，β=1 ESS/K 0.9988；最低分候选相对候选均值的关节 RMS 偏移 4.435 mrad。配对成功率变化的 bootstrap 95% 区间 [-25%, +0%]。

## 解释边界

成功/失败平均分是每条完整 SFT rollout 的查询均分；它检验跨状态结局分离，不能代替同状态候选的因果排序。最低支撑使 cup 成功率从 16/20 降至 14/20，但 click 与 shoes 分别升至 15/20、9/20，因此三任务没有一致的下降证据。在线 20 场景只估计这组冻结场景的变化，置信区间应与点估计一起阅读。

## 训练配置与数据

每项任务使用匹配的 SFT checkpoint 生成同观察 K4 候选，50 条专家 episode 用于训练，20 条用于独立离线测试。五折校准后使用全 50 条训练最终模型，每个模型训练 10,000 步，batch 256，每 1,000 步保存。本轮使用专家与策略二分类目标；讨论中的候选对排序损失尚未用于这批结果。
